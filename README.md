# Calculadora en Python

**Descripción**:  
Una calculadora simple desarrollada en Python que permite realizar operaciones básicas como suma, resta, multiplicación, división, así como operaciones adicionales como potencia, raíz cuadrada y factorial.

## Funcionalidades

- **Sumar**: Realiza la suma de dos números.
- **Restar**: Realiza la resta entre dos números.
- **Multiplicar**: Multiplica dos números.
- **Dividir**: Divide dos números (con control de división por cero).
- **Potencia**: Calcula la potencia de un número.
- **Raíz cuadrada**: Calcula la raíz cuadrada de un número.
- **Factorial**: Calcula el factorial de un número.
